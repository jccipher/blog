## Editorial summary

Anthropic has introduced a new feature for Claude Code called artifacts, which allows users to generate live, shareable web pages from their sessions. These artifacts can include PR walkthroughs, system explainers, dashboards, and release checklists, which update automatically as the session progresses. The artifacts are built using the full context of the session, including the codebase, connectors, and the conversation itself. This eliminates the need to wire up data sources or stand up infrastructure. When Claude Code updates an artifact, the open page refreshes in place, and teammates see the updates immediately. Every publish is a new version at the same link, with version history available for restoration. Artifacts are private by default and can be shared with teammates and the organization directly from the page. Admins can manage access with an org-level toggle and role-based scoping, set retention policies, and get org-wide visibility through the compliance API. The feature is currently in beta for Claude Team and Enterprise organizations, available via the Claude Code CLI and desktop app, with pages viewable in any browser. Use cases include debugging, legal audits, privacy reviews, security findings, FinOps, software engineering, design, staff engineering, SRE, and engineering management. Claude Code builds the page and gives users a link, which can be opened in a browser or desktop app and shared from the header. Updates publish to the same URL automatically.

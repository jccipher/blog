Responses API 已成为开发者构建代理软件的核心构建块。本文摘要展示了五个案例，展示了 API 的实际应用，包括协调工具的多代理系统、检测错误、运行工作流程和推出由 AI 驱动的产品。

编辑摘要

OpenAI 的《从提示到产品：Responses API 一周年》报告概述了过去一年中 Responses API 的进展和应用。该 API 使开发者能够构建可以执行复杂任务的代理系统，如监控 AI 代理行为、分析大型数据集和生成交互式产品演示。报告中展示了五个案例研究，每个案例展示了 API 的不同用途。Raindrop AI 使用 Responses API 来检测和修复 AI 代理故障，而 Repo Prompt 使用它进行深度推理工作流程。Collxn 是一个为黑胶唱片收藏者提供服务的平台，使用 API 来实现对话界面。Arcade 使用 API 将屏幕录制转换为交互式产品演示，而 Hexagon 使用它来衡量 AI 输出中的品牌可见性。报告突出了 Responses API 的多功能性及其在帮助开发者构建更强大的代理系统中的作用。然而，报告也指出该 API 存在一些限制，例如需要特定的工具和模型，并且基准测试结果不能作为通用的安全保证。

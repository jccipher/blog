Claude Code 现在允许用户从他们的会话中生成实时、可共享的网页，称为工件。这些工件可用于调试、协作和文档，并且会随着会话的进行自动更新。该功能目前处于 Claude Team 和 Enterprise 组织的测试阶段。

编辑摘要

Anthropic 为 Claude Code 引入了一个新功能，称为工件，允许用户从他们的会话中生成实时、可共享的网页。这些工件可以包括 PR 演示、系统说明、仪表板和发布检查清单，并且会随着会话的进行自动更新。工件是基于会话的完整上下文构建的，包括代码库、连接器和对话本身。这消除了需要连接数据源或搭建基础设施的需要。当 Claude Code 更新工件时，打开的页面会立即刷新，团队成员可以立即看到更新。每次发布都是同一链接下的新版本，可以随时恢复。工件默认是私有的，可以直接从页面上与团队成员和组织共享。管理员可以使用组织级别的切换和基于角色的范围管理访问权限，设置保留策略，并通过合规性 API 获得组织范围的可见性。该功能目前处于 Claude Team 和 Enterprise 组织的测试阶段，可通过 Claude Code CLI 和桌面应用使用，页面可在任何浏览器中查看。使用场景包括调试、法律审计、隐私审查、安全发现、FinOps、软件工程、设计、高级工程师、SRE 和工程管理。Claude Code 会生成页面并提供链接，用户可以在浏览器或桌面应用中打开该链接，并从页眉处共享。更新会自动发布到相同的 URL。

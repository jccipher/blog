编辑摘要

OpenAI 的 GPT-5.3-Codex 已经展示了执行长期任务的能力，例如在一个持续 25 小时的会话中从零开始构建设计工具。实验涉及以 'Extra High' 推理运行 Codex，生成了大约 30,000 行代码，并使用了约 1300 万个标记。这展示了 Codex 在遵循指令、保持任务焦点和自我纠正错误方面的改进能力。重点从一次性智能转向长期自主工作，实际应用包括多步骤执行和飞行中调整方向。实验还突出了持久项目记忆的重要性，其中规格、约束和状态存储在 markdown 文件中，以防止偏离并保持稳定的 '完成' 定义。结果表明，长期编码正朝着减少看护和更多委托与防护措施的方向发展。然而，该实验并非生产部署，模型的表现受制于限制，包括需要结构化上下文和缺乏一般性的安全保证。

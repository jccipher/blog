编辑摘要

任务在多个 Skill 之间流转时，即使每个技能都通过准入，授权的用途限制仍可能丢失。本期结合技能组合研究与携带证据的消息提案，讨论如何在真正执行动作时再次检查授权和当前状态：签名记录或历史成功本身并不足够。评测材料还涉及两类问题，接口变化可能打乱已训练策略，扫描文档任务也可能在搜索、取页和数字识读之间失败。推理部分转向完整会话，分析工具等待、缓存保留与 KV 容量的相互影响。容量增加不意味着每个 token 更快，调度论文也保留了延迟变差的案例。上述结论均为作者报告，本刊未做独立复现；PCM 是研究提案，并非 MCP 标准。试点应围绕授权传递、接口迁移和相同负载下的服务比较展开。

2026-W45 · 发布日期：2026年11月2日 · Asia/Shanghai。 观察窗口为 [10月26日03:00，11月2日03:00)，对应 UTC [10月25日19:00，11月1日19:00)。本期为独立双语多来源综述，不进入每日单来源队列。六份一手材料包括五篇预印本和一篇维护者工程文章；已核读正文与版本记录，未独立复现实验。

面向平台架构师的四条判断

  1. 把 Skill 新增视为系统变更。 组合会改变既有权限的使用方式，应检查产物、审批信号和目的地址在下游的用途。
  2. 把断言绑定到可观测证据。 消息发送方通过认证，仍不等于消息内容得到证实；历史成功收据在关键动作前仍需新鲜度检查。
  3. 模型与接口共同版本化。 字段顺序、工具编码和执行规则均属于部署系统；冻结模型迁移与等预算适配应分开评估。
  4. 以完整会话为优化对象。 工具等待、缓存驻留和解码容量相互影响；平均延迟、峰值吞吐和 KV 容量是不同目标。

以上为编辑判断，不是 LATENTX 独立验证的研究结论。

主题精选

1. CoSA：单个 Skill 通过准入，组合后仍可能丢失授权

优先阅读 · v1，10月26日。 CoSA: The Conflict of Skills Attack in Real-World LLM Agent Ecosystems。

在288个受控任务、五个模型与三个 Harness 上，每个技能池最多新增5%的 Skill，违规率从35.02%升至58.45%，既有权限与 Skill 保持不变。OpenClaw 招聘场景的防护实验将违规率从65.28%降至6.67%，正常任务完成率从66.67%变为65.00%。

在产物交接中保留用途限制与授权条件。这是固定评测网格的结果，不是生产事故概率；防御证据仅覆盖更窄的领域与 Harness。

2. PCM：携带证据的消息需要独立信任边界

高优先级 · v1，10月29日 · 研究提案，并非 MCP 标准。 PCM: A Proof-Carrying Message Protocol for Verifiable Multi-Agent Communication。

该提案使用签名追加日志支持事实断言，授权链源自人的授权，且只能收窄；Agent 自报不能构成证明。作者的926条消息测试中接受了10条虚假断言，均使用过期证据。

用 Agent 无法改写的记录验证动作收据，并在执行前复核当前状态。可信签名方与执行见证方是前提；证据不证明新鲜度、完整性或良好意图。协议基线包含建模实现，不能当作生产部署审计。

3. 固定模型比较可能否决有潜力的 Harness 接口

高优先级 · 10月27日首次提交，10月28日 v2。 Your Policy Is Secretly a Harness: The Decision Geometry of Agent Interfaces。

在 KL 正则控制假设下，部署回报可分为 Harness 上限与策略失配。在 Qwen3.5-2B 的 MiniWoB++ 实验中，仅反转观测字段顺序，最优决策不变，训练后模型成功率却从85.0%降至19.2%。

固定序列化格式，分别评估即时迁移和等预算适配。受控任务支持机制分析；以更强教师估计编码 Harness 的最优策略仍是代理指标，不能代表通用能力上限。

4. TreasuryQA：覆盖从搜索到扫描识读的完整链路

高优先级 · v1，UTC 10月28日。 TreasuryQA Bench: Can AI Agents Work an Archive of Scanned Financial Records?。

70个问题对应1,435份扫描出版物，通过 Dropbox 仿真环境、MCP 与 OCR 完成。十组固定版本的模型与 Harness 均采用高推理强度，每题尝试三次。Claude Opus 5.5 配合 Claude Code 的 pass@1 为64.8%；校正多重比较后，相邻排名差异并不显著。

保存页级证据，用数值容差判分。只公开三个完整例题，多数任务私有；提供方硬件与服务并发未受控，所列模型成本不含 OCR 费用。

5. TAO：联合调度工具就绪、缓存价值与放置

高优先级 · v1，10月27日。 TAO: Tool-Aware Joint Scheduling for LLM-Based Agentic Serving。

DeepSeek-V4 Flash、两节点且每节点4×H100、SWE-Lite、64个 worker，相对各指标最强基线，平均任务延迟降低26.8%、平均 TTFT 降低36.3%、解码吞吐提升29.5%。基线包括 Dynamo、轮询及缓存感知 vLLM、ThunderAgent；节点缓存价值观测随时间衰减。

同时测量工具返回后的等待与完整任务耗时。最大收益不能泛化；Qwen3-32B 在 SWE-verified、128个 worker 时，延迟比最强基线差2.5%。比较必须携带缓存策略与预测误差。

6. Mistral Large 4：KV 容量不等于解码速度

高优先级 · 维护者页面标注10月29日，最早公开时间未独立确证。 Day 0 support for Mistral Large 4 on vLLM。

8×GB300、NVFP4、TP8 与 TP8+DCP8 对比，不启用推测解码，输入8k–60k、并发至128时，DCP 每 token 解码慢16–28%。显存利用率0.85时 KV 容量从3.60M升至28.76M token；这是容量，不能当吞吐倍率。

当 KV 驻留成为会话瓶颈时考虑 DCP。该比较的前缀缓存匹配状态未确证；P/D 实验明确关闭前缀缓存，不应将两组实验拼接。

架构决策与取舍

决策 收益 代价与验收证据
在副作用边界检查授权 跨 Skill 保留动作、对象与用途 增加检查和误拦截；保留允许执行的对照任务
将证明保存在 Agent 无法改写的位置 动作报告可验证 仍需运维签名方并检查新鲜度
将模型、提示、schema 与 Harness 共同发布 可定位回归来源 增加评测组合，适配预算单独比较
扩容前评估工具感知调度 可能减少空转和工具返回等待 需观测预测误差、规划开销及公平性
仅在容量受限时分片 KV 支持更长驻留会话 集合通信增加延迟，须匹配负载和缓存状态

PoC 与验收指标

以下为编辑提出的试点门槛，不是论文结果，也不构成上线授权：

  • 组合测试： 在新增 Skill 前后运行相同的100个合成业务请求；未授权写入或外传为零，允许任务完成率下降不超过2个百分点，逐一检查被拦截对照任务。
  • 证据测试： 重放伪造、过期、跨租户、重复收据，并覆盖重启；无效证据触发关键动作为零，依赖当前状态的动作前必须重新读取。
  • 接口迁移： 固定 checkpoint 与任务集，每次仅改一个接口元素；记录有效完成、正确率、工具错误、token 与成本。非劣界限设为2个百分点，附任务级 bootstrap 区间；等预算适配另行评估。
  • 服务测试： 固定模型、精度、硬件、输入输出长度及工具延迟分布，扫描16/32/64会话；冷暖缓存分别比较。记录 p50/p95 TTFT、工具返回等待、完整任务延迟、吞吐、缓存命中、失败和会话公平性。只有 p95 任务延迟至少改善10%、失败不增加且吞吐下降不超过5%才进入下一阶段。
